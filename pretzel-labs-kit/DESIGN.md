# Pretzel Labs — как собирать остальные страницы

Этот кит нужен для одного: чтобы страница, которую соберёт другой человек, выглядела так, будто её делал тот же дизайнер, что и главную.

Все значения ниже **сняты с живой главной страницы**, а не придуманы. Если возникает спор «а как правильно» — правильно так, как здесь.

```
tokens.css     — подключить первым. Токены + готовые классы .pl-*
starter.html   — рабочий скелет страницы. Начинать копированием этого файла
assets/        — небо, крендели, иконки, пейзаж
fonts/         — два woff2, больше сайту не нужно
fluted-glass.js — опционально, шейдер «рифлёного стекла» (см. раздел «Стекло»)
```

Открыть `starter.html` в браузере — он самодостаточен и уже собран правильно.

---

## 1. Главное за минуту

Если читать нечего больше, прочитайте это:

1. **Кольцо 4px — подпись всего сайта.** `box-shadow: 0 0 0 4px rgba(221,229,237,.7)` есть почти на каждом контейнере. На ховере оно становится оранжевым. Не заменяйте его обычной рамкой.
2. **Два шрифта, и они не взаимозаменяемы.** Space Grotesk — только заголовки. DM Sans — всё остальное. Курсив бывает только внутри заголовка и только как смысловой акцент.
3. **Оранжевый `#f64c26` — валюта.** Одна главная кнопка на экран. Остальное — тёмное или белое.
4. **Небо — это фон, а не картинка.** Фотографии облаков идут подложкой под контент, а не самостоятельным блоком.
5. **Скругления крупные и дискретные:** 100px (всё капсульное), 30 / 24 / 20 / 14. Промежуточных значений нет.
6. **Ничему не задавайте фиксированную высоту.** Это главный источник поломок в исходной вёрстке — см. раздел 9.
7. **Брейкпоинтов ровно два: 1024 и 640.** Не добавляйте свои.

## 2. Цвет

| Токен | Значение | Где |
|---|---|---|
| `--pl-ink` | `#1d1d1d` | заголовки, основной текст |
| `--pl-muted` | `#4d585f` | вторичный текст, ссылки в меню |
| `--pl-accent` | `#f64c26` | акцент: ссылки «Learn more», прогресс, курсив в заголовке |
| `--pl-accent-hi` | `#ff6a45` | **только** светлый край градиента главной кнопки |
| `--pl-surface` | `#edf1f4` | светлые панели, заливка на ховере |
| `--pl-sky` | `#cfe3f7` | плоский голубой под фото-карточками |
| `--pl-ok` / `--pl-warn` / `--pl-risk` | `#10b981` / `#ff8b06` / `#f51c23` | статусы в чипах |

**Правила.**

- Текст на фотографии — только `--pl-ink` и только на светлом участке. Серый `--pl-muted` поверх фото читается плохо: на главной это уже один раз сломалось на пейзаже.
- `--pl-accent-hi` нигде не используется как самостоятельный цвет.
- Больше двух акцентных пятен в одном экране не ставить.

## 3. Типографика

```
Space Grotesk  600   — все заголовки
DM Sans        500   — базовый вес текста (не 400)
DM Sans        600   — подписи, метки, кнопки, жирные числа
```

| Класс | Размер | Интерлиньяж | Трекинг |
|---|---|---|---|
| `.pl-h1` | `clamp(52px, 7vw, 100px)` | 1 | −2px |
| `.pl-h2` | `clamp(40px, 5vw, 64px)` | 1.05 | −1.5px |
| `.pl-h3` | `clamp(34px, 4vw, 48px)` | 1.05 | −1px |
| `.pl-h4` | `28px` | 1.2 | −0.5px |
| `.pl-lead` | `20px` | 26px | — |
| body | `16px` | 1.3 | — |
| `.pl-small` / `.pl-tiny` | `14px` / `13px` | — | — |

Отрицательный трекинг обязателен — без него заголовки рассыпаются и перестают быть похожими на главную.

**Курсив.** Приём страницы: в заголовке одна фраза курсивом, иногда акцентным цветом.

```html
<h2 class="pl-h2">Заголовок, <em>с акцентом</em></h2>
<h1 class="pl-h1">Your pipeline, <span class="pl-accent">finally honest</span> with you.</h1>
```

Одна курсивная вставка на заголовок. Курсив в основном тексте не используется.

Заголовкам ставьте `text-wrap: balance`, абзацам `text-wrap: pretty` — на главной так везде.

## 4. Скругления, тени, ритм

**Радиусы:** `100px` капсулы (кнопки, чипы, пилюли) · `56px` панель навигации · `30px` большие карточки · `24px` стеклянные панели · `20px` плитки бенто · `14px` мелкие вставки.

**Тени — их всего три:**

```css
box-shadow: 0 0 0 4px rgba(221,229,237,.7);   /* кольцо, база */
box-shadow: 0 0 0 4px rgba(246,76,38,.55);    /* кольцо на ховере */
box-shadow: 0 8px 30px rgba(29,29,29,.08);    /* парение стеклянной панели */
```

Кнопки несут собственную внутреннюю тень (см. `tokens.css`) — не смешивайте её с кольцом.

**Ритм.** Секция: `padding: 130px 30px 0`, на ≤1024px верхний отступ становится `90px`. Контейнер `max-width: 1200px; margin: 0 auto`. Ширина текстовых колонок: заголовок до 640px, абзац до 600px, подпись до 320px.

Внутренние промежутки берите из ряда `6 · 10 · 14 · 20 · 30 · 70`.

## 5. Компоненты

### Навигация

Копируется на каждую страницу без изменений — это единственный элемент, который обязан быть идентичным везде. Разметка в `starter.html`, скрипт бургера там же (12 строк, без зависимостей).

Плавающая белая капсула, `position: fixed`, `top: 20px`, `max-width: 800px`. На ≤1024px ссылки уезжают в выпадающее меню под бургер, на ≤640px у логотипа остаётся только крендель без текста — иначе кнопка «Request access» не помещается и текст в ней переносится в две строки.

### Кнопки

Ровно три вида, четвёртого не заводить.

```html
<!-- главная: оранжевая, одна на экран, при желании в «ореоле» -->
<span class="pl-btn-halo">
  <a class="pl-btn pl-btn--primary" href="#">Get a demo <span class="pl-btn__arrow">→</span></a>
</span>

<!-- тёмная: навигация и вторичная конверсия -->
<a class="pl-btn pl-btn--dark" href="#">Request access <span class="pl-btn__arrow">→</span></a>

<!-- призрачная: белая капсула поверх фотографии. Тоже в ореоле! -->
<span class="pl-btn-halo">
  <a class="pl-btn pl-btn--ghost" href="#">Watch a 4-min tour</a>
</span>
```

Стрелка `→` в кружке — часть кнопки, не декор. Ховер у главной и тёмной — `filter: brightness(1.08)`, у призрачной — заливка `--pl-surface`.

**Ореол обязателен для обеих кнопок в паре.** `.pl-btn-halo` — это 6px полупрозрачной
рамки вокруг капсулы. Если обернуть только главную, её цветная форма будет 48px против
59px у соседней, и пара будет выглядеть кривой, хотя внешние габариты совпадают.
Внутренняя капсула у всех типов — ровно **48px**.

**Подписи на кнопках короткие.** Длинный текст на второй кнопке распирает её вдвое шире
первой; на мобильном обе кнопки растягиваются на всю ширину через `.pl-btn-row`, и
разница становится особенно заметной. Два-три слова — потолок.

### Мелочи, на которых спотыкаются

**Значки — это SVG, а не текстовые символы.** Галочка `✓` геометрически центруется в кружке
корректно, но «чернила» глифа сидят выше середины строки, и значок читается как кривой.
Используйте `.pl-tick` со встроенным SVG внутри.

**Текстовые ссылки-действия («Learn more →») должны иметь зону клика.** Голая строка 14px —
слишком мелкая мишень и без обратной связи на наведении. Класс `.pl-link-cta` добавляет
padding и такой же отрицательный margin: мишень растёт, текст остаётся на месте.

**Заголовок и абзац разного кегля рядом не выравниваются сами.** Верхние границы строк у них
совпадут, но у крупного заголовка над капителью гораздо больше воздуха, чем у мелкого текста,
и пара читается как съехавшая. На главной правая колонка сдвинута вниз на измеренные 5px
(только на десктопе). Если делаете такую же двухколоночную шапку — проверьте и сдвиньте.

**Почта — это `mailto:`, а не кнопка.** В исходной вёрстке адрес в футере был тёмной
капсулой со ссылкой на `#cta`, то есть вёл не туда. Контакт — обычная текстовая ссылка.

### Карточки и плитки

```html
<div class="pl-tile">
  <div class="pl-tile__bg" style="background-image:url(assets/feature-2.jpg)"></div>
  <h3 class="pl-h4">Заголовок</h3>
  <p class="pl-small pl-muted">Подпись</p>
</div>
```

`.pl-tile` — плитка бенто (радиус 20px). `.pl-card` — крупная карточка (радиус 30px, серая заливка). У обеих кольцо, обе меняют его на оранжевое при наведении. `.pl-tile__bg` при наведении медленно наезжает (`scale(1.06)`) — контент остаётся на месте.

### Стекло

Фирменный приём: «скриншот интерфейса» как матовая панель поверх фотографии неба.

```css
background: rgba(255,255,255,.55);
backdrop-filter: blur(14px);
border: 1px solid rgba(255,255,255,.7);
box-shadow: 0 8px 30px rgba(29,29,29,.08);
border-radius: 24px;
```

Класс `.pl-glass`. Внутри — чипы статуса `.pl-chip--ok/warn/risk`, крупное число (Space Grotesk 56px), полоса прогресса `.pl-bar`.

**Стекло всегда лежит на фотографии.** На белом фоне эффект пропадает и панель выглядит грязной.

Опционально `fluted-glass.js` даёт эффект «рифлёного стекла» (WebGL-шейдер поверх фото). Он тянет ~122 КБ стороннего кода с esm.sh — подключайте только если он действительно нужен, и только по `IntersectionObserver`, когда блок подъехал к экрану.

### Бегущий свет по краю

`class="pl-glass pl-edge-light"` — по контуру панели за 9 секунд проходит еле заметный световой блик. Держите его тонким: это акцент на одном-двух блоках, а не украшение всех подряд. Автоматически отключается при `prefers-reduced-motion`.

## 6. Изображения

Четыре семейства, у каждого своя роль. Смешивать нельзя.

| Семейство | Файлы | Роль |
|---|---|---|
| **Небо** | `hero-clouds.jpg`, `hero-clouds-1250.webp`, `feature-2.jpg`, `feature-3.jpg`, `feature-timeline.jpg` | фон героя и подложка под стекло. Пастельно-голубое с розовой подсветкой |
| **Крендели 3D** | `eyebrow/1–6.webp` | «глазок» над заголовком секции (216px), декоративные булавки по краю (160px) |
| **Знак** | `eyebrow/7.webp`, `eyebrow/7-64.webp` | логотип. 64px-версия для 32px-слотов, полная — для 120px в CTA |
| **Иконки** | `icons/1–4.webp` | оранжевый лайн-арт, 56px, в плоских плитках |
| **Пейзаж** | `cta-hills-cut2.webp` | только нижний край финальной карточки |
| **Герой** | `pretzel-2d.webp` + `-460` / `-840` | крупный крендель внизу первого экрана |

**Правила.**

- 3D-крендели и лайн-арт вместе в одном блоке не появляются.
- Крендель-«глазок» центрируется над заголовком секции, 216px на десктопе / 120px на мобильном.
- Пейзаж используется **только** прижатым к нижней границе карточки.
- У героя обязателен `srcset` — иначе на телефон уедет картинка 1377px в бокс 228px.

## 7. Движение

| Что | Как |
|---|---|
| Стандартный переход | `.2s` |
| Кольцо на ховере | `box-shadow .3s` |
| Наезд фона в плитке | `transform .8s cubic-bezier(.2,.8,.2,1)` |
| Подъём стекла | `transform .5s` + рост тени |
| Смена шага/таба | `width .5s cubic-bezier(.2,.8,.2,1)` |

Кривая одна на весь сайт: `cubic-bezier(.2, .8, .2, 1)`.

Всё, что двигается непрерывно, обязано вставать на паузу вне экрана и уважать `prefers-reduced-motion`.

## 8. Производительность — что нельзя ломать

Главная сейчас: **FCP 124 мс** на десктопе, **LCP 1.4 с** на медленном 4G, 12 запросов, ноль кросс-доменных. Чтобы новые страницы не обрушили эту планку:

1. **Никаких CDN-скриптов в критическом пути.** Шрифты локальные, React не нужен — страницы статические.
2. **Preload на LCP-элемент.** Обычно это фон героя или крупная картинка. Разные варианты для мобильного и десктопа задаются через `media` у `<link rel=preload>`.
3. **Всё ниже первого экрана — `loading="lazy" decoding="async"`.** Первые две картинки (логотип и герой) — наоборот, `eager`.
4. **Отдавайте картинку по размеру отрисовки.** Проверьте: `naturalWidth` не должен превышать ширину бокса больше чем вдвое.
5. **Не прячьте страницу до полной загрузки.** Приём «показать всё разом через `opacity: 0`» мы пробовали и замерили: FCP вырос со 124 мс до 4.1 с, а LCP вообще перестал фиксироваться — Chrome не считает контентными элементы с нулевой прозрачностью. Вместо этого делайте первый экран лёгким.
6. **Видео — `preload="none"`** и запуск по `IntersectionObserver`.

## 9. Ловушки исходной вёрстки — не копируйте это

В исходном экспорте главной есть несколько ошибок. Они уже исправлены на главной, но если вы копируете куски её кода, то унесёте их с собой.

**Фиксированные высоты.** Контейнерам задавали `height: 760px`, `height: 220px`, `aspect-ratio: 1.1/1` вместе с `overflow: hidden`. На узком экране содержимое выше — и его срезает: у одной карточки внутренний блок вылезал за родителя на 32px, у другой обрезалась нижняя строка. **Пишите `min-height`, а не `height`.** В `tokens.css` на ≤1024px стоит страховка `height: auto !important`.

**Абсолютно прибитые панели в гридах.** В блоке «How it works» карточка — это грид
`repeat(auto-fit, minmax(320px, 1fr))`, а стеклянная панель прибита `position: absolute;
right: 40px; bottom: 40px`. На десктопе она аккуратно попадает в пустую вторую колонку. Но
ниже 1024px грид схлопывается в одну колонку, текст занимает всю ширину — и панель ложится
прямо поверх него. **Если позиционируете что-то абсолютно, рассчитывая на свободное место
в гриде, обязательно снимайте это позиционирование на узких экранах** — иначе «свободное
место» исчезает вместе с колонкой.

**Абсолютное позиционирование декора.** Пейзаж в CTA был прибит через `top: 430px` при фиксированной высоте карточки. Совпадало ровно на одной ширине: шире — обрезало, уже — оставляло серую полосу, а после привязки к низу картинка уехала под текст и убила контраст. **Правильно: элемент в потоке, `margin-top: auto` в flex-колонке** — тогда он всегда прижат к низу и никогда не наезжает на текст.

**Навигация без замены на мобильном.** Ссылки просто скрывались через `display: none`, бургера не было — разделы становились недостижимы. В ките бургер уже есть.

**Тесная панель навигации.** На 375px «Request access» переносилась в две строки и вылезала из капсулы ещё в оригинале. Решается скрытием текстового логотипа на ≤640px.

## 10. Чек-лист перед сдачей страницы

- [ ] Навигация скопирована один в один, активный раздел подсвечен
- [ ] Ровно одна оранжевая кнопка на экран
- [ ] Заголовки — Space Grotesk с отрицательным трекингом, одна курсивная вставка
- [ ] На каждом контейнере кольцо 4px, на ховере оранжевое
- [ ] Стекло лежит только на фотографии
- [ ] Проверено на 1440 / 1024 / 640 / 390 — нигде нет горизонтальной прокрутки
- [ ] Ни у одного блока нет `height` с фиксированным значением
- [ ] Ни один текст не лежит на тёмном участке фотографии
- [ ] Картинки ниже первого экрана ленивые, у LCP-картинки есть `preload` и `srcset`
- [ ] Проверено с `prefers-reduced-motion: reduce`

## 11. Если нужно что-то, чего здесь нет

Сначала посмотрите, нет ли на главной похожего блока — почти наверняка есть. Если действительно нет, соберите новое из существующих примитивов: кольцо + радиус из ряда + один из трёх типов кнопок + шрифтовая пара. Новые цвета, радиусы и тени не заводить: именно на этом консистентность и рассыпается.
